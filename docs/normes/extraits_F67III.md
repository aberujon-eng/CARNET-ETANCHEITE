## Identité / portée
- F67-III du CCTG Travaux approuvé par arrêté du 28/05/2018, JORF 14/06/2018
  (entrée en vigueur). La version 2018 du fascicule n'a PAS de commentaires
  intégrés → ce document CETU 2019 les fournit (fascicule en pages de droite,
  commentaires en pages de gauche).
- Champ : travaux NEUFS d'étanchement des tunnels/OS. Réparations (injections)
  EXCLUES, sauf systèmes généralisés assimilés au neuf (commentaire 2).
- Avis technique CETU : reconnaissance procédé, validité 5 ans, renouvelable
  (utile folio 00 « références et contrôles »).

## Structure (pages fascicule)
- **1 Dispositions générales** (p.11-29) : domaine, terminologie (1.2),
  documents titulaire (1.3), PAQ/NOG (1.4), environnement (1.5), programme
  et études d'exécution (1.6).
- **2 Spécifications des procédés** (p.31-47) : 10 familles :
  géomembranes synthétiques (2.2.1) ; feuilles bitumes polymères FPM/FPA
  (2.2.2) ; asphalte coulé bicouche 8+22 / monocouche (2.2.3) ;
  géomembranes bitumineuses (2.2.4) ; SEL (2.2.5) ; SIL intrados (2.2.6) ;
  géosynthétiques bentonitiques ± géofilm (2.2.7) ; enduits
  d'imperméabilisation adjuvantés (2.2.8) ; enduits par minéralisation
  (2.2.9) ; joints de voussoirs compressible/hydro-expansif/mixte (2.2.10).
  Nouveautés 2018 vs fascicule initial : bentonitiques, géomembranes
  bitumineuses, asphalte extrados, joints de voussoirs, SIL, minéralisation.
- **3 Modalités d'exécution** (p.49-79) :
  3.1 qualité du support (béton coulé/projeté §3.1.4, parois moulées §3.1.5,
  soutènements métalliques §3.1.6, voussoirs §3.1.3.c) ; 3.2 épreuves de
  convenance ; 3.3 géomembranes synthétiques (fixation, soudure, raccord
  entre phases, compartimentage §3.3.1.d, dispositif contrôle/injection
  §3.3.1.e, protections §3.3.1.f, points singuliers §3.3.1.g, contrôles
  §3.3.1.h) ; 3.4 asphalte ; 3.5 géomembranes bitumineuses ; 3.6 SEL
  (application, épaisseur du film §3.6.3, bullage, contrôles) ; 3.7 SIL ;
  3.8 bentonitiques ; 3.9 enduits adjuvantés (mise hors d'eau, épaisseur,
  contrôles) ; 3.10 minéralisation ; 3.11 joints de voussoirs (réception,
  colle, pose, contrôles) ; 3.12 annexes (abréviations p.81).
